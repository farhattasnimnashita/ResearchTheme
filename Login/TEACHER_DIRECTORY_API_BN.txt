Teacher directory API update

তোমার project-এ main.go replace করো এবং teacher_directory.go, teacher_directory_test.go যোগ করো। ZIP-এর বাকি source তোমার দেওয়া version-এর কপি। .env/DB/executable বাদ আছে; নিজের .env রাখবে। Student UI বদলানো হয়নি।

Login folder-এ:
gofmt -w teacher_directory.go teacher_directory_test.go
go test ./...
go run .
আগের server চললে Ctrl+C দিয়ে থামাবে। DATABASE_URL আগের Supabase database-ই হবে। তুমি ইতিমধ্যে teacher_directory SQL চালিয়েছ, আবার চালাতে হবে না।

Website-এ login করার পর একই browser-এ:
http://localhost:8080/api/teacher-directory
JSON array দেখাবে। Login ছাড়া 401, SQLite mode-এ 503।

Teammate frontend:
async function loadTeachers() {
 const response = await fetch('/api/teacher-directory');
 if (!response.ok) throw new Error('Teacher list load failed: ' + response.status);
 const teachers = await response.json();
 return teachers;
}

Live ব্যবহারের জন্য পরিবর্তন GitHub-এ push করে deploy করতে হবে। Teammate একই app origin থেকে fetch করবে; আলাদা frontend origin-এর CORS configuration এখানে যোগ হয়নি।
